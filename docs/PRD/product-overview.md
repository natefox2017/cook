# Cook Product Overview V1

## Positioning

Cook converts recipes found on social platforms into structured personal recipes.

Core flow:

Share from TikTok / Instagram / YouTube / Pinterest / web
→ Cook Share Extension
→ Async AI extraction
→ Recipe library
→ Cooking mode
→ Grocery list

## V1 User Goal

Save a recipe with almost the same effort as saving a video.

Normal flow:
1. Tap Share
2. Choose Cook
3. Return to original app

AI processing happens in background.

## Main Features

P0:
- Share Extension import
- Recipe extraction
- Personal recipe library
- Recipe detail
- Cooking mode
- Grocery list
- Search
- Collections

P1:
- Meal planning
- OCR/photo import
- PDF import

## Excluded

No community system in V1.
