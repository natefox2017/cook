# Cook Design System V1

## Platform

iOS only.

## Visual direction

Apple Liquid Glass inspired navigation + premium European recipe app.

## Typography

Brand direction:
Claude-inspired humanist sans.

Implementation font:
Source Sans 3 (SIL Open Font License)

Fallback:
SF Pro / system font.

Rules:
- Titles: Semibold/Bold
- Body: Regular
- Navigation: Medium
- Metadata: Regular

No serif fonts in product UI.

## UI Rules

- Food photography is the main visual element.
- Glass material is used for navigation and controls, not every card.
- Avoid dense dashboards.
- Avoid excessive icons.
- One primary action per screen.

## Navigation

Floating Liquid Glass Tab Bar.
