## 状态定义
- PENDING：未确认
- APPROVED：用户已明确回复“确认”
- REJECTED：需重做
- SUPERSEDED：已被同名新设计替换

禁止把“看起来没问题”“大概这样”“先做着”视为 APPROVED。
