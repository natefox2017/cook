- UI-010 只在来源输入已可靠持久化、能够继续入队时短暂显示，然后完成 host request。不能等待 AI；网络请求失败但本地已可靠保存不属于 UI-011。持久化机制由接口任务冻结。

- UI-013 发生在主 App，来源与部分结果确实保存后才显示；关键步骤缺失可添加截图或文字，保留已有内容与疑点。

- UI-012 是编辑主表单示例，保留原始来源；图片未覆盖键盘、字段错误、保存失败与未保存退出，均未批准。
- UI-002-L 是读取库的加载态，不是导入 AI 进度。后台导入的轻量“整理中”条目还需单独补图。
- UI-005-S 是一次购物份量的预览，原食谱不被覆盖。只有安全明确的数值换算，未知/适量保留原文；未知原始份量的禁用提示还未补图。
