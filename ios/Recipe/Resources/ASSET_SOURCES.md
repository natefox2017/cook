# Bundled assets

## Lora

Source: [Google Fonts Lora](https://github.com/google/fonts/tree/main/ofl/lora), retrieved 2026-10-07.

File: `Fonts/Lora-Variable.ttf`. It includes regular, medium, semibold, and bold weights. The SIL Open Font License is retained in `Fonts/OFL-Lora.txt`.

## Sample recipe photography

The sample resources are exact copies of the user's existing recipe-app designs:

- `SampleRecipeSheet.jpg`: [IMG-002 / My Recipes](https://drive.google.com/file/d/1R0FHplovG_ifhgwba3FmVCcGCbbmqzUG/view), also in PR #13 at `design/review-2026-10-03/references/IMG-002.jpg`, blob `64ffebd410f062f52e866414c1d4539c5bde9f6f`.
- `SamplePastaReference.jpg`: [IMG-003 / Recipe Detail](https://drive.google.com/file/d/1zUSkURsiTX5NmfP8EUiORJ7Tj7nroOXS/view), also in PR #13 at `design/review-2026-10-03/references/IMG-003.jpg`, blob `b35e6ef6676563e012c6b4c3dfa3c66e54e3b3da`.

`RecipeImage` draws only the food-photo crop, excluding the mockup's controls and typography. A screenshot is never the actual interface. Sample recipes are opt-in and identified as examples; user-imported recipes never receive a sample image as an invented result. User-selected photos are resized locally and rendered from actual saved data.

## App icon

`AppIcon.png` is the user-approved RecipePouch cooking-pot icon used by the asset catalog. `AppIcon.svg` is a lightweight editable vector companion. `RecipeBrand.imageset/RecipeBrand.png` is an exact copy of the approved raster icon for the account sheet; the vector companion is not substituted for the approved artwork. The selected white-background, full-color design was approved on 2026-10-07.
