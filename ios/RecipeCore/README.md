# RecipeCore

无 UI 的 Swift library，为主 App 提供本地食谱、购物清单、简单计划、偏好设置和计时逻辑。它自身不是可安装 App，不包含 Share Extension。

```sh
swift test --package-path ios/RecipeCore
```

`IngredientAmount` 保留原始用量文字，数值/单位仅由调用方提供已证实的数据。
`scaled(by:)` 只做正倍数 Decimal 乘法：未知数值保持未知，原文保持不变，精度损失/溢出/下溢拒绝。不解析文字、不换单位、不推断置信度。

该类型是本地领域工具，不是冻结的 API/数据库模型。导入合同冻结后由独立 adapter 接入，禁止直接添加 Codable 把它当传输格式。

## 本地数据与持久化

- `Recipe` 等模型只描述本地应用状态，保留来源 URL、原文和未知用量，不直接充当后端 DTO。
- `RecipeIngredient.from` 仅解析用量输入框内的明确数字、可精确表示的分数和单位。范围、模糊描述、无法精确表示的分数保留原文。
- `RecipeStore(fileURL: nil)` 为内存模式；传入文件路径时，变更先通过校验并原子写入完整快照，写入成功后才发布到界面。
- 文件无法读取、解码或格式版本不受支持时，保留原文件和最后一次成功读取的状态；所有写入（包括重置）被阻止，直到修复文件后重新读取成功。
- 默认库为空；只有用户明确选择时才调用 `loadSampleRecipes()`。示例以稳定食谱 ID 去重，并标记 `Sample recipe`。
- 购物清单只合并同名、同单位、数值已知且未勾选的条目；不转换单位、不合并未知用量。非有限小数的份量换算显示精确比例表达式并保留未知数值。
- 每天每个餐次保存一条简单计划，删除食谱时清理计划和购物清单的来源引用，保留购物任务本身。
- `resetLibrary()` 清空本地食谱、购物、计划与本地资料，恢复默认设置；不覆盖坏文件。

## 计时

`CookingTimer` 保存绝对截止时间，前后台切换无需按秒累减。`remaining(at:)` 向上取整并限制在零至剩余时长；暂停记录剩余秒数，恢复建立新的截止时间。`isRunning` 表示存在活动截止时间，结束时由界面显示完成状态、处理通知并停止计时。完成不会自动推进烹饪步骤。

产品最低版本为 iOS 18.0；macOS 14 下限用于 Swift 6 命令行测试与 Observation。主 App Bundle ID 为 `com.shopkivoo.recipe`；签名、App Group 和后端由应用工程单独配置。本目录的测试覆盖来源与精度保留、完整落盘、写失败不发布、坏文件保护、购物合并、计划清理和计时恢复；iOS 界面编译由应用工程的 Xcode CI 验证。
